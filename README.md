# Music Field Manual

Interactive field companion for the **Akai MPC XL** (MPC 3.9.1) and the **Jackson Soloist SL2 DX**. Get a loop out of the box tonight, then learn the machines properly.

No account. Progress, notes, pickup, and the change-drill log stay in this browser.

Public source: [github.com/SharpMeow/music-field-manual](https://github.com/SharpMeow/music-field-manual)

## Features

- Day-one setup and a 12-step lo-fi loop recipe for the XL
- Hardware map, button reference, dirt chain, swing, and firmware notes
- Jackson spec, Floyd Rose survival, chords you can hear, a one-minute change drill, metronome, A minor pentatonic
- Dispatch desk for current firmware / guitar news
- Dark theme by default, light theme available
- Search (`⌘K` or `/`)

## Run it

```bash
git clone https://github.com/SharpMeow/music-field-manual.git
cd music-field-manual
npm install
npm run dev
```

Then open the URL Vite prints (default port 8080).

```bash
npm run typecheck
npm run build
```
