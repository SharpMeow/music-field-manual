# Security

This is a static reading companion. It has no accounts in use, stores
nothing on a server, and keeps your checklists and notes in your own
browser.

If you find a security problem anyway, such as a way to run script on the
site, a leaked secret in the repository, or a dependency with a known
exploit that affects this app, please report it privately:

**[Report a vulnerability](https://github.com/SharpMeow/music-field-manual/security/advisories/new)**

Please do not open a public issue for it. You should hear back within a week.

Only the current `main` branch is supported.
