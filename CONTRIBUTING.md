# Contributing to Music Field Manual

Hey. Glad you are here.

Fork the repo. Make a branch. Open a pull request against `main`. That is the whole dance.

## A good PR

- The book lives in `src/data/`. Widgets live in `src/components/`. Keep that split.
- No accounts, no database, no live news scrape.
- Keep the two-machine frame: MPC XL and Jackson Soloist SL2 DX.
- American English. No em dashes. Warm comments.
- Do not add analytics, affiliation claims, or a DAW.

```
npm run typecheck
npm run build
```

Both should pass before you ping me.

Read `README.md` and `docs/AGENTS.md` first. Please.
